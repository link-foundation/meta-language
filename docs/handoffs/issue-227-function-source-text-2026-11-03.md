## Drafted source paths

`javascript-function-text.js` owns shared source units, exact nonempty UTF16
intervals and source text projection. A bounded unique source directory checks
every static and lexical interval; a lexical interval remains inside its actual
source owner. Intrinsic implementation bodies cannot supply original source
spans. Source units are shared by stable identifiers rather than numeric indexes,
so composition does not change span coordinates. Primitive and noncallable
receivers produce the actual TypeError path. Bound functions request native
metadata without disclosing target source. Runtime closures select their actual
owner/template site. Missing source remains an explicit source request; current
ordinary name, length and prototype properties never substitute for it.

The protected Function.toString body uses one shared opcode. Its pending record
retains the actual receiver, intrinsic realm and source/native category, checked
against the actual preceding instruction and current receiver register. A pending
metadata request cannot hide a child frame. Resume consumes complete nonempty
text and clears the pending record; metadata supplies no executable authority.
The common public/live source driver handles that same explicit transition.

`javascript-function-source-publication.js` derives template intervals from the
same CST lexical site ordering used by the checked source frontend. Plain captures
retain their complete actual source unit. Both private original-module witness
creators now retain complete original source, original declaration intervals and
projected lexical sites. Existing archive formats remain unchanged. Original
module composition restores original aliases and exact text rather than exposing
bootstrap renamed declarations. A generated or missing original site stays
unmapped instead of inventing text. Initial publication, initialized legacy
modules and additional source units carry the same metadata; joins preserve
existing units and reject conflicting text for one identity.

The Node metadata port independently re-derives the actual pending request and
requires the adopted current heap. Source requests cannot fall back to compiled
or native-looking source. Actual native owners use a protected native text reader
without executing their bodies. Bound metadata uses an independent inert native
bound function witness, never the represented target or mutable metadata. This
implementation-dependent category witness is restricted to Node >=22.15 <23 or
>=24 <25 and explicitly reports uncovered versions. Native Proxy carrier text is
not an original source witness; represented handles expose exact source through
their portable methods. This boundary remains explicit in controls and vision.

The protected callable catalog now includes toString and deduplicates the actual
restricted caller/arguments getter/setter identity. Those accessors retain the
actual descriptor and nonextensible native identity metadata while their body
uses the shared portable TypeError primitive, ignoring receiver/arguments. The
Function constructor has an independent constructibility/realm classification;
this does not implement dynamic Function creation or permit its native body as
fallback. Every previous owner and assertion remains in place.

Primary contracts:
[Function.prototype.toString](https://tc39.es/ecma262/2025/multipage/fundamental-objects.html#sec-function.prototype.tostring)
and [%ThrowTypeError%](https://tc39.es/ecma262/2025/multipage/ordinary-and-exotic-objects-behaviours.html#sec-%throwtypeerror%).
Textual correspondence is not observed behavior.
