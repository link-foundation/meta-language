## Actual source changes

`rust-source-place-replacements.js` adds `assign field` to the existing exact
replacement interface. The executable graph retains a held RHS, the actual current
original mutable source binder, complete source positions and a declaration-index
path. Reconstruction wildcards the old selected leaf, retains every unchanged
sibling binder and publishes Unit plus exactly the rebuilt root. The independent
plan checks that full graph, actual operand identity/type/owner/Box projection,
output order and original span. Its operand mode is owning value, rather than a
shared String suffix. Public facet keys and transport schema remain unchanged.

`rust-owned-record-effects.js` routes ordinary and explicit projected field writes
through that operation in the composed source profile. RHS evaluation happens
before selecting the latest containing SSA name, so RHS sibling writes survive.
Whole-root assignment remains its existing distinct operation. The parser's
`rust-owned-record-state.js` clears old descendant move entries only after actual
complete parent-field assignment; unrelated missing components remain missing.

`rust-source-partial-state.js` derives a fresh containing image from the actual
prior declaration inventory and availability. Every containing path ancestor
must be initialized; the selected old leaf can be moved or conditional. Only the
selected replacement subtree becomes available. Its other actual components keep
their previous ownership states. Private interpreter proof objects bind real
state values to their actual current storage root and original source identity.
They are not source metadata, generated constructors, masks or runtime entities.

`rust-source-place-transform-regions.js` lifetime-inspects a partial root only
after independently checking the actual assignment or selected call/rebuild
graph. Its real RHS still passes normal complete ownership checks and transfers
once. Checked helpers and standard String/Vec field operations require complete
actual selected subtrees, preserve unrelated missing siblings and share the same
component publication. Multiple selected formals retain actual disjoint paths;
whole-root/root-only Box payload acquisition still requires the complete selected
root. Original callee/Vec helper bodies, callbacks and outputs are retained.
Successful publication consumes the old containing revision and creates its real
successor; stale references cannot be revived by an initialization spelling.

`rust-borrowed-source-regions.js` recognizes private proofs only for actual state
transport. Packet fields, binding and end-of-expression inspection can carry a
partial image; ordinary whole reads/moves/borrows/calls/returns still check all
components. State-tail variables get controlled lifetime inspection using their
checked complete source position. Branch snapshots retain every allocated
component state and charge their extra cells to the existing budget. Joins merge
actual per-branch availability and rebase returned state/loan coordinates before
issuing current storage proofs; earlier aliases retain their old coordinates.
The source authoring recipe registers the new module for later automatic native
publication. No native implementation was handwritten.

Thirty-one positive and twenty invalid originals are appended under the retained
Rust/Node ranges. They cover repeated/conditional initialization, two missing
fields, sibling writes, block transport, nested/Box records, parent-subtree
restoration, sibling RHS transfer, RHS effects, whole overwrite, selected helpers,
multiple formals, callbacks/captures and String/Vec intrinsic/helper composition.
Invalid inputs
retain missing fields/ancestors, incomplete whole publication, shared/immutable
mutation, overlapping references, wrong types and reused owning operands. These
are authored native-control inputs, not passes or requirement counts.

Independent controls check exact RHS/rebuild structure, absent archived proof
objects, forged masks/operands/binders and a same-core-type assignment retargeting
whose local graph remains valid but whose final whole use must remain invalid.
An additional same-type forged String-clear graph remains locally valid but must
fail when it selects the actual moved receiver. Twelve scenarios retain Links
text, binary and all four emitted target bodies.
No existing source input, assertion, oracle, version range or gate was removed.

Contracts follow [Rust assignment evaluation](https://doc.rust-lang.org/reference/expressions/operator-expr.html#assignment-expressions)
and [partial moves](https://doc.rust-lang.org/rust-by-example/scope/move/partial_move.html).
