## Actual source behavior drafted

`rust-source-place-replacements.js` supplies `Rust source place replacement 1`
under the existing `sourcePlaceTransform` facet. It retains one actual root
binder/current input, declaration-order field path, original span, exact supported
operation and complete pre-evaluated operand positions. The executable body
remains ordinary common-core syntax: String push_str concatenates actual field
text and suffix; String clear constructs empty text; Vec push appends exactly
one actual element. All three rebuild the full actual enclosing root and return
Unit plus that new root. There is no fake source function header or replacement
native implementation.

The independent validator derives receiver identity from actual qualified field
positions and reuses standard String owner/suffix rules. It checks every source
field projection and unchanged ancestor/sibling through the shared exact path
checker. The replacement leaf must use its actual lexical result binding once
at the selected field; hidden effects, different operands, duplicate Vec elements,
changed siblings, forged metadata and unknown operations refuse. Owning element
positions keep canonical owners and types, including nominal declarations.
Actual field inspection retains its independent 100,000-work bound.

The exclusive-method reader retains its private actual intrinsic/operand origin
alongside the existing admitted source write. The ordered effect lowerer visits
the real operand once, including its observations and nested state effects,
then constructs the replacement against the latest real root. A disjoint nested
argument call has its own checked reconstruction and preserves this operation's
selected field. Root, ownership, overlap and surviving-loan source checks remain;
the previous intrinsic-field guard is replaced by the complete operation contract.
Older whole-root and closed-body paths keep their existing lowering.

The existing place-region interpreter handles the checked replacement ABI: it
requires the exact initialized source binder/current epoch, checks operand modes,
acquires the actual old root once, and publishes the new complete root. Shared
text suffixes are read with their actual loans, and owning Vec elements move
once. Replacement operand lifetime names are checked against the actual caller
scope before call-like instantiation. Old-root aliases are not revived.

Ordinary source checking, typed Links validation and source-free projection reuse
the existing facet dispatch. The datatype-reference walker now retains replacement
operand positions as well as root positions; alpha renaming retains both input
columns. The new source module enters automatic author receipts. Native policies
and generated assets remain deferred to automatic publication after the full
draft; no handwritten Rust semantics or generated-file edits were added.

## Independent controls drafted

Ten appended positive originals cover direct String append/clear, borrowed owning
Unicode suffixes, scalar/owning String/nominal Vec elements, nested ancestors,
readonly-result helpers, disjoint nested argument mutation and observable operand
order. Four invalid originals retain old String/Vec loans, use of an already
transferred owning element, and an invalid nontext push_str argument.

Structural controls check all three actual operation forms and field paths;
remove contracts; forge roots, operands or lifetimes; change siblings; inject
hidden operand effects; and duplicate/reorder Vec appends. Full Links text/binary
reload controls retain both the nested selected-call transformation and intrinsic
replacement, compare JavaScript/Rust/Lean/Rocq emission and keep the JavaScript
output assertion. All controls remain unexecuted under the existing explicit
Rust, Node, edition and dependency ranges. No old input or assertion was removed.

Latest authored inventory: 477 positives in nineteen groups, 413 literal
originals plus 64 actual-source scenarios. The mixed composition group has 112
positives and 38 refusals. These are input counts, not observed passes, drafted
requirement counts or a completion percentage.
