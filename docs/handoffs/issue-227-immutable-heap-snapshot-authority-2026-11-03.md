# Immutable heap validation authority seam

`sealJavaScriptOrdinaryHeapSnapshot` makes a private immutable data copy, validates the complete heap, and only then records its exact frozen root identity in a private validation witness. Recursive copying preserves primitive bits, sparse-array shape and aliases, refuses metadata accessors/native callable or Symbol values, and uses null-prototype data records so later mutation of a caller's object prototype cannot supply inherited heap facts. Physical immutable graph sharing grants no semantic admission by itself. Caller flags, a copied receipt, `Object.freeze` and exported immutable copying cannot forge the heap witness.

The public heap validator recognizes only these exact privately validated immutable heap identities. Mutable, forged or changed public snapshots continue through its full original checks. New immutable copies share previously owned immutable subgraphs. Heap mutations still construct new untrusted roots and are fully rechecked before publication. No caller-supplied validation callback or unchecked mutation channel exists. Private WeakSet/WeakMap uses are validation/copy controller metadata, and never implement represented WeakMap/WeakSet contents.

`createJavaScriptCallMachineSnapshot(program,machine)` owns immutable program/frame/heap copies and runs the complete ordinary machine validator. `stepJavaScriptCallMachineSnapshot(snapshot)` calls the same public machine step and preserves normal external suspension/resumption boundaries. Its Continue result publishes another validated immutable snapshot; unchanged certified heaps/program subgraphs share their actual identity. Resumed external states must enter the normal full snapshot boundary again. The witness proves validation and immutability, not original-source body correspondence or execution history.

This opt-in facade provides a real repeated-read seam: weak get/has on an unchanged certified heap no longer repeat whole-directory heap validation. The facade does not replace default embedding ownership and does not freeze caller-owned mutable snapshots. Whole-frame/program validation remains. Mutation still incurs snapshot validation/copying and weak entry-array copying; persistent weak-entry/directory structures and incremental mutation receipts remain the next performance obligation. No full end-to-end sublinear WeakMap/WeakSet conformance is claimed.

Deferred controls in `translation-javascript-heap-snapshots.test.js` cover source alias mutation, nested immutability, receipt forgery, accessors, exact primitive values, real machine query steps, changed-root validation and structural sharing. No tests, imports of represented bodies, generation, validation commands or compilation ran while drafting this seam. Root owns architecture and source-author registration.
