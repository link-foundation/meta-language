This experiment projects all 17 inputs of the existing closed Rust text
certificate kernel from original LinkId primitive transport. The input remains
an actual source-free network with its selected `sourceTextValueProjection`
facet. The existing raw identity and certificate checker runs first; its old
projected tables are used only by the tests as an independent comparison.

The shared recipe selects ordered scalar String queries from actual token,
declaration, parameter, position, core and condition links. A core variable's
elided name follows its actual binding-reference target. It does not resolve an
owner by an equal name. The unchanged UTF-16 symbol kernel interns those query
values in the old projector's exact first-observed order, starting with the
unchanged 107 fixed certificate symbols. Null/non-String input has a separate
sentinel from an empty String. Original owner handles, ordered references and
primitive Number payloads remain separate from String values.

`policy.mjs` generates the complete JavaScript rules and a Links artifact with
all 66 automatically translated Rust definitions. It embeds the unchanged
JavaScript fixed-table and symbol rule sources (29 and 22 native definitions
when translated separately), then adds query, table and consistency rules.
Generated continuation names follow the combined program. The host only
collects primitive tags, Number/Boolean values, exact UTF-16 units,
actual ordered references and the frozen symbol prefix. It supplies no old
projected table or dynamic dictionary to the numeric kernel. The resulting 17
tables are checked by the unchanged complete certificate kernel.

The selected immutable-array transport has explicit bounds: at most 100,000
network members, 1,000,000 field/reference edges, 100,000 queried strings and
100,000 UTF-16 units for each admitted string transport. Query repetitions count
against that bound. A generated exact code-unit guard checks the frozen prefix
and every inherited scalar code against the actual String payload, so
contradictory primitive columns refuse before complete table output. These
finite domain guards are not a universal memory or performance guarantee for graph collection, traversal, immutable array copies
or the existing mandatory raw checker. Number payloads retain signed zero,
NaN and infinities until the unchanged certificate rejects inappropriate
values; this is no promise about NaN payload-bit preservation.

This adds no production source selector, native pre-Serde capture adapter,
native Program re-encoding or paired source frontend. Rust output is generated
here; native compilation/execution remains CI work. Other source models and
whole runtime/resource/termination claims remain outside this experiment.

The separate `native-observations.test.mjs` oracle is CI-only. CI with
`ORIGINAL_LINK_COMPLETE_TABLE_NATIVE=0` authenticates and plans all 66 unchanged
definitions and runs injected process contracts. Setting that flag to `1` in CI
also compiles the complete artifact and an external consumer, then executes 45
whole-table or exact-refusal comparisons. Thirteen originals and four coherent
edits retain both archive premises before exactly identical input bits share an
invocation. The 28 raw-owner refusals are separate JavaScript host checks.
Strict reversible bit transport retains every row boundary and cell within the
unchanged one MiB stdout limit; the mechanical consumer is bounded to four MiB.
Successful actual native execution alone writes
`issue-195-artifacts/original-link-complete-table-native-observations.lino`.
Planning, injected contracts and native execution remain pending CI evidence.

Run the bounded checks with Node 22:

```sh
node scripts/with-cache-cleanup.mjs --event test -- node --test --test-concurrency=1 experiments/original-link-complete-table-projection/projection.test.mjs
node experiments/original-link-complete-table-projection/generate.mjs --check
```
