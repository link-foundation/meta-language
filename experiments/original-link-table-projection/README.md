# Original-link fixed-symbol certificate tables

This JavaScript-first experiment projects eleven complete certificate tables
from actual original LinkIds: `context`, `kinds`, `positions`, `paths`, `layers`,
`functions`, `operations`, `parts`, `inputs`, `allocations` and `items`.
It retains the existing role registry and the unchanged complete raw
text-certificate checker. No production source model, native codec or existing
fixture changes.

The host collects only primitive raw scalar payloads and the existing ordered
parent/label/child/reference transport. Every original ID remains in its separate
anchor vector. The linked policy records complete row/column instructions and
the unchanged fixed certificate symbol dictionary. The generated numeric kernel
reads those original edges, resolves registered handles and materializes the ten
new whole tables. It does not compare reconstructed objects or infer identity
from names. Source operation codes still come from the shared certificate data;
the unchanged final certificate checks their grammar, owner and condition facts.

Root, edge, scalar-tag and dictionary bounds run before interpretation. Actual
root and child operation markers also require their actual String scalar tag;
the fixed marker code alone cannot classify a non-String node. An invalid root
operation marker returns the linked policy's precise `[-22]` refusal row. Actual
null, missing/unregistered nodes and unknown fixed symbols retain distinct
representations. Primitive Number payloads are copied without normalization.
Tests retain negative zero and nonfinite Number values in projected cells, then
check the existing certificate refusal. This introduces no nonfinite source
admission or guarantee about distinct NaN payload bits. The existing outer data
guard still refuses nonfinite values before its kernel call.

For each of the thirteen original complete-source fixtures, text and binary
archives produce exact whole-table equality with the original projector under
the independently checked raw-ID correspondence. The unchanged complete kernel
returns the same decision after all eleven tables are substituted. A coherent
saved parameter retarget executes its changed result after both archive formats;
actual source interval changes alter the projected numeric cells. Host/raw owner
forgeries still refuse, and direct primitive cross-owner/payload controls change
the generated tables and fail the same complete certificate.

The six remaining tables are `tokens`, `declarations`, `parameters`, `cores`,
`names` and `units`. Their values still use the original projector, including
arbitrary String interning. The comparison adapter remaps only their identity
columns; it does not implement those table values. Whole-network enumeration,
the existing experimental raw checker, native pre-Serde host integration, direct
native Program ownership/re-encoding and paired capture/replay remain open.

The entire numeric rules module, including the unchanged generated role kernel,
automatically emits all 29 Rust definitions and a complete Rust runtime artifact.
No Rust algorithm is handwritten, rewritten or extracted. Source-free checked
Links reload executes the complete emitted JavaScript kernel. Native compilation
and execution are separate CI work. The selected array interpretation uses
read-only primitive values; repeated scans and immutable copies can be costly,
and this experiment makes no native resource or performance claim.
