# Native grammar outcome transport experiment

This is a finite verification experiment for the
[authoritative CST transport target](../../../docs/vision.md#grammar-import-conversion-and-reverse-conversion).
The JavaScript [owned outcome experiment](../README.md) supplies the preceding
public-parser controls. Public default CST transport and native integration
remain unfinished.

The wire producer reads the actual Rust CSTs for all nine outcome declarations.
A Links policy defines their complete field order, omission/null rules and
variant transport. Generated borrowed visitors share a counting sink and a
direct graph sink. Counting checks expanded occurrences, scalar bytes and depth
before graph allocation. The candidate rejects depth settings above 256; this
is not arbitrary-depth stack safety.

The bridge producer extracts the original number conversion from its actual
source owner, retaining its validation and a whole-parent inverse. The existing
generic encoder, decoder limits and number semantics remain unchanged.
Generated parent/child candidates and receipts require an explicit output
directory outside the checkout or in ignored `.issue-195-work/` scratch:

```sh
node experiments/grammar-outcome-network/native-transport/wire/generate.mjs --output-dir OUTPUT_DIRECTORY
node experiments/grammar-outcome-network/native-transport/bridge/generate.mjs --output-dir OUTPUT_DIRECTORY
```

These commands generate source only. Never compile Rust locally. Use the
repository's resource wrapper, one job and bounded JavaScript checks; preserve
the generated receipts and original publication evidence.

The probe creates an independent fresh JavaScript oracle with eleven actual
parser outcomes and three constructed boundaries. Proposed native checks cover
complete ordered values, binary64 bits, negative zero, exact and one-below
resource limits, and text/binary replay of each actual native graph. Additional
native-only ordering/refusal controls are not JavaScript physical-alias parity.
The test harness collects case failures before deciding whether it may write
its post-assertion report. No requirement-ledger observations are recorded.

The runner's default only authenticates and plans sources. Explicit native
execution requires Linux GitHub Actions, its opt-in environment and an owned
external `RUNNER_TEMP`; guards run before any compiler or scratch operation.
The compiled crate is the explicit frozen Git snapshot
`3780504667f4abe167a270263453e54be2b1cc43`, with the candidate parent/child and
probe overlaid in scratch. Current working hashes are recorded separately.
Publication metadata cannot silently replace that frozen baseline.

Native test development dependencies also need independent parser sources.
The runner downloads these registered, checksum-verified oracle build inputs
into its owned CI scratch. Production parser removal remains unfinished.

CI retains source identities, the fresh oracle, tool versions, all process logs
and any actual native post-assertion report. Cargo uses locked/offline dependency
resolution and one build job; compiler execution and probe execution have
separate bounds. Failed or missing reports never establish support. The
shared diagnostic-order correction below also applies to production sources.
Package exports and the default projection retain their existing behavior.
Public integration still requires paired APIs, ownership/provenance
validation and the remaining exact-commit acceptance obligations.

Links publication archives retain complete original private authors and exact
portability/harness changes. Source and JavaScript controls alone do not prove
native compilation or native behavior. Read the producer and runner receipts
before refreshing any frozen pin.

The `diagnostic-order/` author reads all nine actual JavaScript diagnostic call
contexts and their native counterparts. It derives exactly two permutations of
complete existing native object members, preserving values and predicates. The
same Links decorator supplies the production correction and the frozen CI
overlay correction, with separate role-qualified receipts and full source
inverses. Historical pins stay historical; explicit current views independently
check actual imports and complete selected declarations. A private one-entry
syntax cache avoids repeated parsing of identical whole source bytes while
checking every caller field and proof again. Dependency assertions retain the
exact locked serializer patch, declared ordering feature and source hashes.

```sh
node experiments/grammar-outcome-network/native-transport/diagnostic-order/generate.mjs --check
```

scratch output. This correction preserves all fourteen original probe cases and
