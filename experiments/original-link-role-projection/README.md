# Original-link certificate role registration

This partial experiment connects the existing exact original-LinkId lookup to
the actual `kinds` input of the closed Rust text certificate. It changes no
production source option, native codec, existing fixture or source model.

`readOriginalLinkRoleTransport` first requires the unchanged raw text-certificate
checker to accept the selected archive. It retains actual original LinkId
anchors, ordered field-relation IDs and their parent/label/child IDs, and ordered
positional references. The existing exact high/low-word kernel supplies numeric
membership ordinals. Full unsigned64 IDs never pass through a Number, and
membership does not establish ownership. Current public JavaScript archives
retain their existing safe-ID boundary.

The shared linked policy contains role instructions for actual source tokens,
declarations, parameters, source signatures, source positions, core expressions,
source operations and main. The generated numeric kernel reads the primitive
transport, registers only those nodes and returns compact anchors, a dense
`kinds` table and occurrence handles. Repeated original IDs share a handle;
equal-looking distinct IDs remain distinct. Contradictory concrete roles and
provisional role nine without an eventual concrete registration refuse. Unrelated
network members create no certificate rows.

All thirteen existing complete source fixtures pass through text and binary
archives. The tests bind the existing table identities to the same actual raw
role nodes, substitute the new `kinds` table, and coherently remap every identity
column of the other sixteen tables. The unchanged complete certificate kernel
then returns its original decision. Those other table values still come from
the existing projector: this experiment does not implement their raw projection.
Seven cross-owner exchanges and seven equal-looking owner clones still refuse
through the existing checker. A coherent saved parameter retarget executes its
changed result after both archive formats.

The entire numeric rules source automatically translates with the existing
explicit immutable-array interpretation. Inputs are primitive read-only values;
there are no indexed writes, observed alias identities or escaping callbacks.
The generated data retains all emitted definitions and the complete Rust runtime
artifact, without source rewriting or extraction. Native compilation and
execution remain separate CI work. Repeated scans and immutable snapshots can
have substantial cost; the occurrence cap is 4096 and there is no native
performance or resource claim.

The remaining public integration boundary is a faithful raw projection of the
other sixteen table values, original-owner retention through native checked
programs and re-encoding, and paired source capture/replay. The host transport
still enumerates the whole network and relies on the existing experimental raw
checker, which indexes and clones it. This is not a scalable selected-graph
adapter or a standalone generic graph decoder.

Run only the bounded JavaScript experiment:

```sh
node experiments/original-link-role-projection/generate.mjs --check
node scripts/with-cache-cleanup.mjs --event test -- node --test \
  experiments/original-link-role-projection/projection.test.mjs
```
